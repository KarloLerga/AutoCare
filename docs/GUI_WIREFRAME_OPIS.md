# GUI wireframeovi - opis

GUI wireframeovi izrađeni su u **Figmi** i priloženi su kao `wireframes/AutoCare_GUI_Wireframes_FINAL.pdf`.

Wireframeovi prikazuju korisnički tok i raspored elemenata, a ne završni pixel-perfect izgled Swing aplikacije.

Glavni prikazi:

1. Prijava
2. Registracija
3. Dashboard
4. Vozila
5. Dodaj vozilo
6. Održavanje
7. Katalog
8. Servisna povijest
9. Novi servis
10. Problemi

Katalog jasno razlikuje informativni raspon cijene od stvarnog računa. Servisna povijest koristi naziv **Stvarni trošak**, jer se tamo prikazuje stvarno unesena cijena servisnih stavki.
